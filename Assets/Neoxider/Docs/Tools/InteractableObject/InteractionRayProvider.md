# InteractionRayProvider

`InteractionRayProvider` selects how interaction rays are generated by a camera. Namespace:
`Neo.Tools`; assembly: `Neo.Tools.InteractableObject`. It requires a `Camera` on the same object.

## Setup

1. Add the component to the camera tagged `MainCamera`.
2. Select `Mode` in the Inspector.
3. Leave each target's `UseScreenCenterRay` off to use the shared camera policy. Enable that override
   only for targets that must always use center rays.

| Mode | Hover ray | Click / mouse down / mouse up ray |
|------|-----------|----------------------------------|
| `Mouse` | Cursor position | Cursor position |
| `ScreenCenter` | Camera viewport center | Camera viewport center |
| `Both` (default) | Camera viewport center | Cursor position |

The center is relative to the camera viewport, including an offset `pixelRect` in split-screen
layouts. Cursor positions must be finite and inside that viewport. Ray creation returns `false`
when required pointer input or the camera is missing, or the viewport has zero size.
A live camera with valid viewport/render-texture dimensions can generate rays while `Camera.enabled`
is false. Direct provider calls and a target's cached center-ray camera preserve this geometry;
`FindOnMainCamera()` retains its main-camera and enabled-provider selection rules.

## Runtime API

| Field | Description |
|-------|-------------|
| `Camera` | Lazily cached camera attached to this component. |
| `Mode` | Gets/sets the serialized ray mode. |
| `TryGetHoverRay(out Ray)` | Gets the hover ray; inspect the returned boolean before using it. |
| `TryGetClickRay(out Ray)` | Gets the click ray independently of hover. |
| `UseScreenCenterForClick` / `UseScreenCenterForHover` | Read-only mode decisions. |
| `FindOnMainCamera()` | Finds the enabled provider on the current main camera; adds one in `Both` mode if absent. Returns `null` when there is no main camera or its provider is disabled. |
| `InvalidateQueries()` | Ends the borrowed raw-hit epoch after an application-controlled world/physics change. Does not simulate or synchronize physics. |

```csharp
InteractionRayProvider provider = camera.GetComponent<InteractionRayProvider>();
provider.Mode = InteractionRayProvider.RayMode.ScreenCenter;
if (provider.TryGetClickRay(out Ray ray))
{
    // Feed ray into the caller's physics query and target-selection rules.
}
```

`FindOnMainCamera()` follows a change of the main-camera tag and does not reuse a provider from the
previous camera. It intentionally creates a component when one is missing, so use `GetComponent`
with an explicit camera reference when scene mutation is undesirable. This global lookup does not
replace an already assigned `InteractiveObject.DistanceCheckPoint` or the component's cached camera.

The provider creates rays. Automatic `InteractiveObject` physics is shared by
[`InteractionPhysicsQueries`](./SharedQueries.md), using the actual ray, camera/viewport and physical
policy. Changing provider mode, disabling the provider or replacing the main-camera provider ends
the prior query epoch. Targets keep all their existing settings and UnityEvents.
