## Native export, hidden samples and archive inspection

Use the public `AssetDatabase.ExportPackage(string[], string, ExportPackageOptions.Default)` against an **enumerated asset-path allowlist** from sanitized, manifest-owned staging. Default does not auto-add dependencies, subdirectories or Library assets; omit `IncludeDependencies`, `IncludeLibraryAssets` and `Interactive`. Do not replace the allowlist with `Recurse` over a broad root. Unity's API supports this exact selection. [ExportPackage](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/AssetDatabase.ExportPackage.html), [options](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/ExportPackageOptions.html).

`Samples~` is UPM's source convention; UPM copies selected samples into visible Assets on import. A native asset export cannot be assumed to carry that hidden payload. Activate only the isolated staging copy, preserve existing child asset/folder metas, and record any new staging-only parent-folder meta. The actual legacy import must confirm the developer-layout resolver and all sibling references; do not treat manual sample copying as UPM import evidence. [Unity package samples](https://docs.unity3d.com/6000.3/Documentation/Manual/cus-samples.html).

Compare the actual exported `.unitypackage` inventory to the selected paths. Its tar members are commonly GUID directories: inspect each **`pathname` payload**, asset bytes and `asset.meta` GUID, not just outer tar filenames. Reject unexpected paths, traversal/absolute paths, duplicated identities, out-of-allowlist vendors and protected files. Validate dependency references, but do not auto-export the dependency closure: external installed prerequisites are intentional. Preserve original GUIDs; never generate replacements to make import appear clean.

If the optional UPM tarball is produced, use a supported pack operation for the actual SDK and inspect the result. Current public6.3 docs mark two-argument `Client.Pack` deprecated and document a three-argument overload requiring a real organization ID; do not invent that value or assume a different SDK signature. It is asynchronous and its returned tarball path/success must be observed. Omitting this optional artifact is preferable to inventing an unsupported pack route. [Client.Pack](https://docs.unity3d.com/6000.3/Documentation/ScriptReference/PackageManager.Client.Pack.html).
