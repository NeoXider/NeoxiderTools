# Golden fixtures

60 fixtures: S01 to S44 (single page) and M01 to M16 (multi-file jobs). Data only; every implementation must reproduce `expected/` from `input/`.

- `fixture.json` (schema `spec/schemas/fixture.schema.json`): what the fixture proves, rules, tiers, mode (`validate` or `convert`), verdict, `force`, `capabilityPatch`, `runs`/`edits`, `expectedStatus` (`oracle` = generated by `oracle/python`, `authored` = written by hand from `docs/EMULATIONS.md`).
- `config.json` (single page) or `job.json` + `config.json` (jobs), `input/` (HTML, CSS, USS, strings, images, partials), `expected/` (UXML, USS, JSON, `diagnostics.json`, `*.png.expect.json`), `expected-final/` (M16).
- `index.json` lists all fixtures. The conventions are specified in `docs/EMULATIONS.md`.
- Validate the data files with `python tools/validate_schemas.py`.
