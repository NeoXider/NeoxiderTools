# Bonus / Slot

**What it is:** composable slot-machine mechanics in `Scripts/Bonus/Slot/`: `CheckSpin` evaluates symbol
matrices in ordinary C#, `SlotSpinMath` computes prices and payouts, `SlotEconomyDefinition` stores symbol
weights and rewards, and `SpinController` drives optional reel/line views and a wallet.

**Contents:** see [Documents](#documents) below. All grid queries use `[column, row]` with row zero at the
bottom; payline queries use `[line, column]`.

---

## Runtime and scene setup

Assign a complete `SpritesData` table, ordered `Row` columns, optional `BetsData` and `LinesData`, and a
wallet implementing `IMoneySpend` / `IMoneyAdd`. Each reel needs its visible symbols plus buffer elements.
Without `LinesData`, fallback horizontal paylines cover the configured visible row range. Buttons can
call `StartSpin`, `AddLine` / `RemoveLine`, and bet-selection methods; code calls the same public APIs.
Line visual objects and LineRenderers are optional. Empty line-view arrays still allow line selection
to cycle within the actual payline definitions.

For rules without views, call `CheckSpin.GetWinningLines(ids, activeLines)` and `GetMultiplayers`, then
`SlotSpinMath.ComputePayout(multipliers, lineBet)` for the same payout `SpinController` credits.
Only contiguous runs of valid non-negative symbol IDs can win; missing-cell ID `-1` does not pay.
Destroyed reel elements are skipped during updates and visible-window recovery. A standalone
`SlotElement` can use automatic Scene labels without requiring a parent reel.

For a full scene spin, check `IsSpinInProgress` before changing layout or bet settings. `IsStop()` only
reports reel motion and may be true between staggered columns. `CompleteActiveSpinImmediately` settles
the active plan once; `CancelActiveSpin` cancels result callbacks and attempts to refund the charged bet.
See `SpinController` for wallet ownership, numeric limits, and lifecycle callbacks.

## Demo scene

`Scenes/Bonuses/SlotExample.unity` in the Demo download (`Assets/NeoxiderDemos/Demo`) runs the full loop with a wallet. Everything is saved in the scene:

| Object | What to look at |
|--------|-----------------|
| `Canvas/SlotUI` | The package prefab with demo data from `Data/Bonus`: **Bets Data** `SlotDemoBets` (5, 10, 25, 50, 100), **Lines Data** `SlotDemoPaylines` (middle, top, bottom, two diagonals), **Sprites Multiplier Data** `SlotDemoPaytable` (three in a row pays x2, x3, x5, x10) and **Money Game Object** = the wallet. `OnChangeBet` and `OnChangeMoneyWin` write the price and payout labels through `TMP_Text.SetText`; **Text Count Line** shows the payline count. |
| `[Demo] Services/Wallet (Money)` | Session-only wallet; the controller sets 500 coins on Play, **+100 coins** calls `Money.Add(100)`. |
| `[Demo] Frame/Content` | Bet and payline buttons call `SpinController.AddBet`, `RemoveBet`, `SetMaxBet`, `AddLine` and `RemoveLine` directly. |
| `[Demo] Services/Demo Controller` | `SlotDemoController`: checks the balance before **Spin**, **Force a win** (`ForceNextOutcomeOnPayline(0, symbol)` + `StartSpin()`), the `ChanceWin` slider and the log of `OnStartSpin` / `OnWin` / `OnLose`. |

A spin costs bet x active paylines; each winning payline pays bet x the symbol multiplier and Auto Payout
adds it to the wallet. The scene is generated by an editor builder; **Neoxider > Demo > Rebuild Active Demo Scene**
restores it.
