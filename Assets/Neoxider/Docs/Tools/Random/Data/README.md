# Tools / Random / Data

## Purpose

Reusable weighted tables for the [Random module](../README.md). `ChanceData` stores configuration; `ChanceSystemBehaviour` owns scene-specific events and copies asset configuration at `Awake`.

## Documents

- [ChanceData](./ChanceData.md)

Create an asset with **Assets > Create > Neoxider > Tools > Random > Chance Data**. See the component guide for direct C# use, sharing rules, and independent copies.
